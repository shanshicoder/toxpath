## 2. 三个必须先解决的关键问题

### 2.1 ⚠️ mpp 元数据损坏（最优先）

5 张 WSI 的物理分辨率元数据全是错的：

```
openslide.mpp-x = 1000.0    ← 占位值，1mm/px 不可能
tiff.XResolution = 25.4     ← 等同 1mm/px，同样不可信
openslide.vendor = generic-tiff  ← 通用 TIFF，无厂商 mpp
```

**视觉推断**（看 `train_001/10_56` patch）：

- H&E 染色正常，细胞核直径约 **12~15 px**。
- 淋巴瘤细胞核典型 6~10μm。若取 8μm / 13px ≈ **0.6 μm/px**，介于 20x(0.5) 与 40x(0.25) 之间，**更接近 20x**。
- L0 尺寸 86016 px 若按 0.5mpp → 43mm，符合常规组织切片大小；若按 0.25mpp → 21.5mm，偏小但仍可能。

**对模型的影响**：HistoPLUS 有两套权重，物理视野都是 112μm：

| 权重 | 训练 tile | 训练视野 |
|---|---|---|
| 20x | 224×224 @ 0.5mpp | 112μm |
| 40x | 448×448 @ 0.25mpp | 112μm |

我们的 patch 1024px：若是 20x → 512μm（约 4.6×4.6 个 HistoPLUS 视野）；若是 40x → 256μm（约 2.3×2.3 个）。

**待办**：向数据提供方确认扫描倍率。在确认前，**先按 20x 假设**走（视觉证据 + L0 尺寸都偏向 20x），训练时从 1024 裁 224 子区域（物理 112μm，匹配 20x 权重）。若最终效果差，切到 40x 假设、裁 448。

### 2.2 ⚠️ 标注是区域级粗多边形，不是像素精确

GeoJSON 里所有几何都是 `LineString`（闭合轮廓），分类为 `Lymphoma` / `Region*`（ROI）/ `Other`：

- mask 是从这些多边形**渲染栅格化**来的，边界是平滑的多边形形状，**不会沿细胞边缘走**。
- 多边形内部会**包含正常间质、血管等非肿瘤成分**；外部可能有零散肿瘤细胞被漏标。
- 这意味着：**像素级 Dice 上限有天花板**（标注本身就不像素精确），不要追求 0.95+ 的 Dice；评估时以"区域召回 / 区域 IoU"为主更合理。

### 2.3 ⚠️ 类别极度不平衡 + 切片间异质性高

- 全量 4953 patch 里只有 **16.5% 有前景**（816 张）。
- 跨切片差异巨大：train_001 有 50.8% patch 含肿瘤，train_005 只有 3.3%。
- 含前景的 patch 里，前景占比多数 < 5%（零星小灶）。

→ 必须同时做：**前景 patch 过采样 + 背景欠采样 + Dice loss + class weights**，单靠任一项压不住。

## 3. 任务定义

- **输入**：1024×1024 RGB H&E patch（JPEG）
- **输出**：1024×1024 二值掩膜，`{0: 背景, 1: Lymphoma}`
- **监督**：从 GeoJSON `Lymphoma` 多边形渲染的 PNG mask（0/255）
- **`Region*`**：在 mask 里体现为"patch 存在"（组织 ROI），不进掩膜类别
- **`Other`**：少量，当前方案先**忽略**（当作背景），若验证集发现 Other 区域被误判为 Lymphoma 再单独处理

## 4. 数据划分方案（5 折留一交叉验证）

**只有 5 张切片，必须按切片划分，绝不能 tile 级随机划分**（同一张切片的 patch 高度相关，tile 级划分会严重高估泛化能力）。

### 4.1 划分

5 折留一（Leave-One-Slide-Out）：

| 折 | 训练切片 | 验证切片 |
|---|---|---|
| Fold-1 | 002, 003, 004, 005 | 001 |
| Fold-2 | 001, 003, 004, 005 | 002 |
| Fold-3 | 001, 002, 004, 005 | 003 |
| Fold-4 | 001, 002, 003, 005 | 004 |
| Fold-5 | 001, 002, 003, 004 | 005 |

- 报告 5 折均值 ± 标准差。
- **不要做 train/val/test 三分**：5 张太少，再切 test 就没意义。test 就是每一折的 val，5 折汇总即测试结论。
- 跨中心泛化（课题主线）目前只能用 CAMELYON17 这类外部数据做，本数据集内部没有"中心"维度。

### 4.2 每折的 tile 级采样

每折训练集约 4000 个 patch，但 83.5% 是背景。采样策略：

1. 把训练 patch 分两类：**前景 patch**（mask 前景 > 0）和 **背景 patch**。
2. 每个 epoch 按 **1:1** 比例采样（前景过采样 / 背景欠采样），即每 epoch 只用 ~800 前景 + ~800 背景随机抽，共 1600 batch-sample。
3. 前景 patch 内部再加权：前景占比 > 20% 的"富前景 patch"权重更高。
4. 背景 patch 不丢弃，但降低频率——它们提供"正常组织"的负样本，对降低假阳关键。

实现：用 `WeightedRandomSampler`，权重 = `1 / (前景像素数 + ε)` 的反比 + 常数项。

## 5. 输入与预处理流程

### 5.1 patch → 模型输入

patch 是 1024×1024，H0-mini 要求边长是 14 的倍数，1024/14 = 73.14 **不是整数**，**不能直接喂**。

方案（按 20x 假设）：

| 阶段 | 操作 | 尺寸 | 物理视野 |
|---|---|---|---|
| 加载 | 读 JPEG + PNG | 1024×1024 | 512μm (20x 假设) |
| 训练增强 | 随机裁剪 224×224（patch 内 + 对应 mask 同位置） | 224×224 | 112μm ✅ 匹配 20x 权重 |
| 推理 | 1024 切成 224 网格（4×4=16 块，无重叠或 32 重叠）逐块推理后拼回 | 1024×1024 | — |

- 224 是 14 的倍数 ✅，H0-mini 原生尺寸，pos_embed 无需插值，最稳。
- 若改 40x 假设：训练裁 448（也是 14 倍数 ✅，匹配 40x 权重），推理切 448 网格（2×2=4 块）。
- **不要**用 784（HistoPLUS 推理尺寸）：224→784 是 3.5× 上采样，物理视野从 112μm 跳到 392μm，与训练分布严重不一致。

### 5.2 归一化

用 **Bioptimus 的 mean/std**（H0-mini 的训练分布）：

```
mean = (0.707223, 0.578729, 0.703617)
std  = (0.211883, 0.230117, 0.177517)
```

JPEG 是 0~255，先 `/255` 再 `(x - mean) / std`。**不要用 ImageNet 的统计量**，否则特征整体偏移，微调要很久才能拉回来。

### 5.3 mask 处理

- PNG 是 L 模式 0/255 → 转成 `int64` 的 `{0, 1}`。
- 纯背景 patch（mask 全 0）**保留参与训练**，但可按需把"完全无组织"的 patch 标 `ignore_index=-100`（目前 patches 已过滤组织，暂不需要）。

## 6. 类别不平衡处理（多管齐下）

### 6.1 采样层（见 §4.2）

`WeightedRandomSampler`，前景 patch 与背景 patch 1:1。

### 6.2 Loss 层

用项目已有的 `DiceCrossEntropyLoss`：

```python
crit = DiceCrossEntropyLoss(
    num_classes=2,
    class_weights=(0.3, 0.7),     # 前景权重高 2.3 倍
    dice_weight=1.0,
    ce_weight=1.0,
    dice_include_background=False, # 只优化前景 dice
)
```

### 6.3 前景占比分布（实测，双峰）

| 前景占比 | patch 数 | 占比 | 含义 |
|---|---|---|---|
| 0%（纯背景） | 4137 | 83.5% | 组织但无肿瘤 |
| <1% | 75 | 1.5% | 零星肿瘤点 |
| 1–5% | 99 | 2.0% | 小灶 |
| 5–20% | 137 | 2.8% | 中等 |
| 20–50% | 164 | 3.3% | 较大块 |
| >50% | 341 | 6.9% | 大块肿瘤 |
| **合计** | **4953** | — | 有前景 **816 (16.5%)** |

**关键观察：双峰分布**。patch 要么纯背景（83.5%），要么大块肿瘤（>50% 的有 341 个），中间过渡带（1–20%）很薄，只占 6.3%。

→ 这意味着：
1. **富前景 patch 其实不少**（>20% 占比的有 505 个，6.9%+3.3%），采样时容易覆盖，不必担心"学不到肿瘤"。
2. **边界 patch 稀缺**（1–20% 仅 311 个）——这些恰恰是分割最难、最该学的。采样时给中等占比 patch 额外加权（除前景过采样外，再对 1–20% 这档加 1.5×）。
3. `class_weights` 取 `(0.3, 0.7)` 合适：前景权重不必太狠，因为采样已平衡；太狠会让模型对零星点过敏、误报增多。

## 7. 数据增强

病理分割的增强有讲究，**不能像自然图像那样随便翻转颜色**：

| 增强 | 推荐 | 原因 |
|---|---|---|
| 水平/垂直翻转 | ✅ | 组织方向无关 |
| 90/180/270 旋转 | ✅ | 同上 |
| 小角度旋转 (±15°) | ✅ | 增加多样性 |
| 随机裁剪 224 | ✅ | 核心增强，见 §5.1 |
| **HED 颜色抖动** | ✅ **必做** | 跨中心泛化的关键，不同扫描仪染色差异大 |
| 亮度/对比度抖动 | ⚠️ 轻度 | HED 已覆盖，别过度 |
| 高斯噪声 | ⚠️ 可选 | 小概率，模拟对焦不准 |
| 弹性形变 | ❌ 不推荐 | 会破坏细胞形态语义 |
| 大幅度色相旋转 | ❌ 禁止 | H&E 是固定三色染色，色相不能乱转 |
| Mixup/CutMix | ❌ 不推荐 | 破坏像素-标签对应关系 |

HED 增强推荐用 `torchstain`（`pip install torchstain`），做 Macenko/Vahadane 归一化 + 随机扰动 α/β。

**关键**：所有几何增强必须**同时对 patch 和 mask 施加完全相同的变换**（用同一组 random params）。

## 8. 评测方案

### 8.1 指标

| 指标 | 说明 | 期望 |
|---|---|---|
| **Dice (前景)** | 主指标，必须乘组织掩膜 | > 0.5 算可用，> 0.7 算好 |
| **IoU (前景)** | 与 Dice 互补 | > 0.4 算可用 |
| **HD95** | 95 百分位 Hausdorff 距离，惩罚边界偏差 | 越小越好 |
| **Precision / Recall** | 看假阳/假阴倾向 | 平衡 |

### 8.2 ⚠️ Dice 必须乘组织掩膜

全 patch 1024×1024 里很多是空白/玻璃。如果直接算 Dice，模型全预测背景也能拿 0.8 的假高分。

```python
tissue_mask = (patch_gray > 0).astype(bool)  # 或 Otsu 阈值
dice = compute_dice(pred & tissue_mask, gt & tissue_mask)
```

### 8.3 汇总方式

- **按 patch 算 Dice，再按切片取均值**（不是全局像素池化，否则大切片主导）。
- **按切片汇总后再取 5 折均值 ± std**。
- 报告每折的 per-slide Dice，看哪张切片最难（预测 train_005 会最难，因为前景最少）。

### 8.4 推理流程

```
1024 patch
  → 切 4×4 = 16 个 224 子块（或带 32px 重叠）
  → 每块归一化 + 模型推理 → 224×224 prob
  → 拼回 1024×1024 prob（重叠区取平均）
  → 阈值 0.5 → 二值 mask
  → 与 GT mask 算指标
```

## 9. 风险与待确认

| 风险 | 影响 | 缓解 |
|---|---|---|
| **mpp 未知** | 输入尺寸策略可能选错 | 先按 20x（裁 224），效果差切 40x（裁 448）；向数据方确认 |
| 5 张切片太少 | 5 折仍可能过拟合 | 冻结编码器、强增强、小 lr 微调；或加 CAMELYON 等公开淋巴瘤数据预训练 |
| 标注粗（区域级） | Dice 天花板低 | 别追求像素级 Dice；以区域召回/IoU 为主；可选 multi-scale 训练（224 + 448）|
| `Other` 类被当背景 | 可能把 Other 误判为 Lymphoma | 验证集若发现，把 Other 标 ignore_index |
| JPEG 压缩 | 1024 JPEG 有压缩伪影 | 若影响明显，从 WSI 重新切 PNG/TIFF patch |
| 切片间异质性 | train_005 难学 | 5 折报 std，重点看难切片的相对提升 |
