# 训练数据集标签重定义方案

> **状态**：✅ 已执行（2026-10-25 17:05 重新生成）· 4953 张标签 mask PNG
> **脚本**：`scripts/relabel_masks.py`
> **范围**：`data/toxpath/train_masks/` → `data/toxpath/train_masks_class/`
> **输出格式**：单通道 8-bit 灰度 PNG，**三类用间隔 128 的像素值区分：0（黑）/ 128（中灰）/ 255（白）**

## 输出格式说明

每张输出 PNG 保留原 mask 的前景空间分布，前景像素按 patch 所属类别取不同的灰度值：

| 像素值 | 显示 | 含义 |
|---|---|---|
| `0` | 黑 | 背景（非肿瘤区域）；**纯背景 patch 整图都是 0** |
| `128` | 中灰 | 前景：零星/小灶/中等肿瘤 |
| `255` | 白 | 前景：较大块/大块/多灶累积肿瘤 |

- **类别1 patch**（纯背景/噪点）：前景被全部剔除，输出**全黑图**（全 0）
- **类别2 patch**：前景位置不变，前景填 **128（中灰）**
- **类别3 patch**：前景位置不变，前景填 **255（白）**

全图**只出现 0/128/255 三个值**，没有第 4 类。

### 为什么不用 1/2/3

1、2、3 在 8-bit 灰度图里都是"接近纯黑"，打开图肉眼完全看不出区别，无法目视质检。
改成间隔 128 的三级灰度后，黑 / 中灰 / 白一眼可分，同时仍然是严格三值编码。

映射对照表随目录一起输出：`train_masks_class/_label_map.json`。

### 训练侧读取

`dataset/toxpath_dataset.py` 的 `mask_to_class()` 按阈值映射成模型类别索引：

| 像素值 | 模型类别 | 类别名 |
|---|---|---|
| `< 64` | 0 | 背景 |
| `64 ~ 191` | 1 | 小灶 |
| `≥ 192` | 2 | 大块 |

用阈值而不是精确等于，是为了让 mask 万一被别的工具重存过（有损缩放）也不至于整片失效。
模型 `num_classes=3`。

## 1. 任务定义

把现有的 **二值像素 mask**（0/255）按 patch 整体特征重新归类为 **图像级三分类标签**：

| 新标签 | 语义 | 对应原前景占比档 | 预期数量 |
|---|---|---|---|
| **1** | 纯背景 / 无肿瘤组织 | 0% | 4137 (83.5%) |
| **2** | 零星、小灶、中等肿瘤（未连成片） | <1% / 1–5% / 5–20% | ~314 (6.3%) |
| **3** | 较大块 / 大块肿瘤（连续成片或多灶累积） | 20–50% / >50% | ~502 (10.1%) |

**输出**：每张 1024×1024 mask 整图填充单一标签值（1/2/3），保持原文件名与目录结构：

```
data/toxpath/train_masks_class/
  train_001/1.0/0_0.png      # 像素值全为 1 或 2 或 3
  train_001/1.0/10_56.png
  ...
  train_005/1.0/...png
```

**注意**：标签值从 **1** 起，不是 0。值 0 留作 `ignore_index`（如未来需要无组织掩膜）。

---

## 2. 核心决策：用什么指标区分标签 2 和标签 3？

### 2.1 三个候选指标

| 指标 | 含义 | 单独用的优劣 |
|---|---|---|
| `fg_ratio` | 前景像素 / 总像素 | 简单稳定，但**无法区分"1 个大块"vs"10 个小灶散布"**——前景占比都是 20% 时语义完全不同 |
| `max_cc_ratio` | 最大连通域面积 / 总像素 | 反映"是否有连续成片的肿瘤"，但**漏掉多灶累积型**（如 6 个 3% 的灶 = 18% 但没一片 ≥20%） |
| `num_cc` | 连通域数量 | 直觉上"多个灶 = 中等"，但**实测区分度极差**（见下） |

### 2.2 全量实测数据（4953 个 mask，816 有前景）

```
num_cc:        min=0  p25=1  median=1  p75=1  p95=3  max=14
max_cc_ratio:  min=0.0000  median=0.3376  mean=0.4314  max=1.0000
fg_ratio:      min=0.0001  median=0.3531  mean=0.4391  max=1.0000

散布度 (fg_ratio - max_cc_ratio):
  mean=0.0078  median=0.0000  p95=0.0444  max=0.3829
  散布度>5% 的 patch: 38 / 816 (4.7%)
```

### 2.3 关键观察

1. **`num_cc` 单独几乎无区分度**：中位数 1、75 分位 1、95 分位才 3。这是因为**标注是粗区域级多边形**，每张 patch 内肿瘤几乎只有 1 个连通区域。如果单看 num_cc ≥ 3 → 标签3，只能识别出几十个 patch，且会和"大块"严重冲突。

2. **`fg_ratio` 与 `max_cc_ratio` 高度重合**：差异中位数 0、95 分位 4.4%，仅 4.7% patch 有显著散布。这意味着**对绝大多数 patch，"前景占比"就是"最大连通域占比"**，两个指标几乎等价。

3. **规则分歧极小**：
   - 规则 A（纯 `fg_ratio ≥ 20%`）vs 规则 B（纯 `max_cc ≥ 20%`）：**仅 9 / 4953 (0.18%) 分歧**
   - 规则 B vs 规则 C（见下）：**仅 6 / 4953 (0.12%) 分歧**

4. **但有 6 个多灶型 patch** 是规则 B 漏掉的：
   ```
   train_001/24_60.png: num_cc=3  max_cc=0.168  fg=0.216   # 3 个灶各 ~7%，加起来 21%
   train_001/26_40.png: num_cc=6  max_cc=0.168  fg=0.203   # 6 个灶，最多 17%
   train_001/39_52.png: num_cc=4  max_cc=0.130  fg=0.255   # 4 个灶，最多 13%
   train_004/31_44.png: num_cc=4  max_cc=0.177  fg=0.215   # 4 个灶
   ...
   ```
   这些 patch 的**最大连通域 < 20%**（按规则 B 是标签2），但**前景累积 ≥ 15% 且有 ≥3 个灶**——病理上属于"多灶性淋巴瘤"，语义上更接近"中等以上"，应归为标签3。

### 2.4 结论：采用规则 C —— 两者结合，主指标 + 辅助规则

> **主指标用 `max_cc_ratio`**（反映"连续成片"，病理语义清晰），
> **辅助规则用 `num_cc` + `fg_ratio`**（捕捉规则 B 漏掉的"多灶累积型"）。

- **不用纯 `num_cc`**：区分度太差，实测中位=1。
- **不用纯 `fg_ratio`**：会误判散布型为"大块"（虽仅 9 例，但语义错误）。
- **不用纯 `max_cc_ratio`**：会漏掉 6 例多灶累积型。

> **采用 max_cc_ratio ≥ 20% 主判 + (num_cc ≥ 3 且 fg_ratio ≥ 15%) 兜底**——虽然只比纯 max_cc 多识别 6 个，但这 6 个是病理上真正的多灶型，且规则复杂度增加极小（一个 or 分支），值得。

## 3. 详细分类规则（决策树）

按以下顺序判定，**第一个命中即定标签**：

```
1. fg_ratio < 0.0005  (≈ 0% 且几乎无任何前景像素)
   → 标签 1（纯背景）

2. max_cc_ratio ≥ 0.20  (最大连通域 ≥ 20% 整图，即连续成片)
   → 标签 3（较大块 / 大块肿瘤）

3. num_cc ≥ 3 且 fg_ratio ≥ 0.15  (多灶累积：≥3 个灶，加起来 ≥ 15%)
   → 标签 3（多灶累积型，兜底规则）

4. 其他
   → 标签 2（零星 / 小灶 / 中等，未连成片）
```

### 3.1 阈值依据

| 阈值 | 取值 | 依据 |
|---|---|---|
| 标签1 上界 | `fg_ratio < 0.0005` | 实测最小前景 0.0001，0.0005 留余量，避免把"5 个像素的噪点"误判为有前景 |
| 标签3 主阈值 | `max_cc_ratio ≥ 0.20` | 与原分桶"5–20% 中等 / 20–50% 较大块"的天然边界 20% 对齐 |
| 多灶 num_cc | `≥ 3` | 全量 p95=3，≥3 即进入前 5% 的多灶 patch |
| 多灶 fg_ratio | `≥ 0.15` | 低于 15% 的多灶过于零星（3 个 5% 灶以下），仍归为标签2 |
| 噪点过滤 | 连通域面积 < 64 px | 8×8 以下的小点视为标注噪点，剔除后再算 num_cc 与 max_cc |

### 3.2 三种规则下的标签分布对比

| 规则 | 标签1 | 标签2 | 标签3 |
|---|---|---|---|
| A: 纯 `fg_ratio ≥ 20%` → 标签3 | 4137 | 311 | 505 |
| B: 纯 `max_cc ≥ 20%` → 标签3 | 4137 | 320 | 496 |
| **C: max_cc + 多灶兜底（推荐）** | **4137** | **314** | **502** |

C 比 B 多识别 6 个多灶型标签3、少 6 个标签2，比 A 少 3 个标签3（这 3 个是散布型，不应归标签3）。**推荐采用规则 C**。

## 4. 处理流程（每张 mask）

```
原 mask (0/255)
  ↓ 二值化 (>127)
  ↓ scipy.ndimage.label (8-连通)
  ↓ 剔除面积 < 64 px 的连通域（噪点）
  ↓ scipy.ndimage.binary_fill_holes（填空洞，避免环形肿瘤被切成 2 个）
  ↓ 重新 label 并计算：
       fg_ratio      = 前景像素 / 总像素
       num_cc        = 连通域数量（已剔噪点）
       max_cc_ratio  = 最大连通域 / 总像素
  ↓ 按决策树（§3）定标签 L ∈ {1, 2, 3}
  ↓ 输出 1024×1024 单通道 PNG，所有像素 = L
  ↓ 保存到 train_masks_class/{slide}/1.0/{X}_{Y}.png
```

**注意**：`binary_fill_holes` 在判定**之前**做，因为它会让"环形标注"变成一个连通域，避免把一个肿瘤误数成 2 个。

## 6. 用途与下游影响

这套三分类标签将用于：

1. **采样权重**：训练时 `WeightedRandomSampler` 给标签2 加权最高（最稀缺且最难学）、标签3 次之、标签1 最低。具体可在 `dataset.py` 里按标签查表得到采样概率。

2. **分类辅助头**（可选）：在 ToxPath 主分割头之外加一个 3 类 patch 分类分支，作为多任务辅助监督，帮助编码器学到"区域密度"先验。

3. **评测分层**：Dice 按标签1/2/3 分别汇总，避免被大量标签1 patch 平均掉。

4. **难度筛选**：标签2 是"边界 / 小灶"，正是分割最难、最该学的；可单独对标签2 做 hard mining。

> **注意**：这套标签是**图像级**的（整图一个值），不能直接当作像素级分割监督。主分割任务仍是二分类（前景/背景），三分类标签用于采样、辅助、评测，不是主 loss 的 target。

## 7. 风险与备选

### 7.1 风险

1. **阈值 20% 是基于现有分桶的边界**，病理上没有严格定义。如果后续训练发现标签3 学得过易、标签2 学不动，可把主阈值从 20% 调到 15%（让更多 patch 进标签3）。
2. **多灶兜底规则（num_cc≥3 且 fg≥15%）只覆盖 6 个 patch**，对这个数据集几乎不改变统计，但在别的数据集上可能影响更大——脚本会留参数可调。
3. **噪点阈值 64 px（8×8）是经验值**。若标注有系统性的细线条，可能误剔。处理前会打印剔除了多少连通域、最大剔除面积，便于人工复核。

### 7.2 备选方案

- **方案 A（纯 fg_ratio）**：实现最简，但误判 9 个散布型。如果你觉得"6 个多灶型不值得加规则"，退回 A 也可。
- **方案 D（按 max_cc 分桶 + 多灶升级）**：把标签2 再细分 2a/2b（max_cc <5% / 5-20%），但用户只要三分类，不采纳。
